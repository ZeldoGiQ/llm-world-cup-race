# Eigene Modell-Logos

Eine Datei hier = ein Avatar. Dateiname ist die Modell-ID, Format SVG (bevorzugt),
PNG oder WebP. Quadratisch anlegen; die Anzeige schneidet kreisförmig zu.

| Datei | Modell |
|---|---|
| `gpt.svg` | GPT-5.5 |
| `claude.svg` | Claude Fable 5 |
| `gemini.svg` | Gemini 3.5 |
| `gemini-flash.svg` | Gemini 3.5 Flash |
| `grok.svg` | Grok 4.3 |
| `qwen.svg` | Qwen 3.7 Max |
| `kimi.svg` | Kimi K2.6 |
| `kimi-k3.svg` | Kimi K3 |
| `deepseek.svg` | DeepSeek V4 Pro |
| `glm.svg` | GLM-5.2 |
| `nova.svg` | Nova Preview |

Rangfolge der Anzeige: eigenes Logo → Lab-Glyphe → Initialen.
